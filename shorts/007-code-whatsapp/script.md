## Sources
- WhatsApp — page Sécurité (whatsapp.com/security, consultée le 19/11/2026) : activer la vérification en deux étapes, ne partager le code avec personne.
- Blog WhatsApp (2026) : la vérification en deux étapes empêche la prise de contrôle du compte même si quelqu'un obtient le code à usage unique.
- UFC-Que Choisir — « WhatsApp : une redoutable arnaque pour vous voler votre compte » : déroulé de l'arnaque, chemin Réglages/Paramètres > Compte > Vérification en deux étapes.
- TechRadar FR / Bbox Mag (2026) : l'« ami » qui demande le code a souvent lui-même été piraté ; le pirate écrit ensuite aux contacts de la victime.

## Points d'exactitude
- Le code peut arriver par SMS ou par appel ; la vidéo parle de SMS (cas le plus courant).
- Chemin : « Paramètres » (Android) / « Réglages » (iPhone) > Compte > Vérification en deux étapes. La voix dit « paramètres de WhatsApp, rubrique Compte », valable sur les deux.
- Depuis 2026, le secret de la vérification en deux étapes peut être un code PIN ou un mot de passe : la vidéo ne précise pas le format.
- « Léa », le code 482 913 et le montant de 300 € sont fictifs.
