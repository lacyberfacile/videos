## Sources
- ESET WeLiveSecurity — credential stuffing : réutilisation des identifiants issus de fuites, recommandations (mot de passe unique, gestionnaire, 2FA)

## Points d'exactitude
- « des centaines d'autres sites » : ordre de grandeur, les tests sont automatisés.
- « il manquera un code au pirate » : la double authentification bloque l'usage d'un mot de passe volé seul ; elle n'est pas infaillible (hameçonnage du code), mais c'est le message débutant correct.
- Le mot de passe affiché (Soleil2004!) est fictif.
