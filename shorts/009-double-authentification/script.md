# Short #009 — La double authentification

**Voix** : Brick (ElevenLabs, eleven_v4)
**Statut** : script rédigé par Claude, publication sans validation préalable (décision de Néo du 10 novembre 2026)

## Texte voix off

| # | Sous-titres / voix |
|---|---|
| 1 | Ton mot de passe a fuité ? Un seul réglage peut encore bloquer le pirate. |
| 2 | Ce réglage, c'est la double authentification. En plus du mot de passe, le site te demande une confirmation. |
| 3 | C'est comme une porte avec deux serrures : voler une seule clé ne suffit plus. |
| 4 | Cette confirmation, c'est un code reçu par SMS, une validation dans une appli, une clé de sécurité ou ton empreinte. |
| 5 | Résultat : toi seul peux autoriser un nouvel appareil à se connecter à ton compte. |
| 6 | Trois réflexes. Un : active-la d'abord sur ta boîte mail, car elle sert à récupérer tes autres comptes. |
| 7 | Deux : active-la ensuite sur tes réseaux sociaux, tes messageries et tes sites d'achat. |
| 8 | Trois : ne donne jamais ce code de confirmation à personne, même au téléphone. |
| 9 | Abonne-toi à La Cyber Facile, pour ne plus te faire avoir. |

## Sources
- Cybermalveillance.gouv.fr — fiche pratique « Mots de passe » (V260505, avec l'ANSSI) : définition de la double authentification, exemples de confirmation (code SMS ou e-mail, validation dans une application, clé de sécurité, biométrie), « vous seul pourrez autoriser un nouvel appareil », importance de sécuriser la messagerie qui sert à réinitialiser les autres comptes.
- Cybermalveillance.gouv.fr — fiche réflexe « Piratage de compte » : activer la double authentification si possible.

## Points d'exactitude
- Accroche : « peut encore bloquer » (et non « bloque toujours ») — certaines attaques par hameçonnage peuvent contourner un code SMS, d'où le réflexe 3.
- « toi@mail.fr » est fictif.
